\# Compose Chat UI



\## Purpose

Realtime secure messaging UI using Compose Multiplatform.



\## Architecture

\- immutable state

\- unidirectional data flow

\- shared UI models

\- adaptive layouts



\## Patterns

\- reverse lazy lists

\- stable message keys

\- optimistic updates

\- streaming rendering

\- desktop split panes



\## Performance

\- minimize recomposition

\- memoize transforms

\- async media loading

\- incremental pagination



\## Desktop UX

\- keyboard-first navigation

\- command palette

\- resizable panes

\- dockable sidebars



\## Avoid

\- mutable shared state

\- blocking UI operations

\- giant composables
